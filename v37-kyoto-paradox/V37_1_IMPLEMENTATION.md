# V37.1 実装仕様書

## タイトル
なぜ京都人は、笑顔のまま人を排除できるのか？【語用論×ポライトネス理論】

## 修正目的
1. 壁時計モチーフを全面廃止し、客自身の腕時計を中心モチーフに統一する。
2. V37で反復して見えた「同じ和室・同じ二人・同じカードUI」を削減する。
3. 48シーンすべてに独立した視覚的役割を与え、同一構図の連続を避ける。
4. ナレーション・字幕・映像・QAの全レイヤーで腕時計設定を一致させる。

## 必須因果
主人が客の手首を見る → 「ええ腕時計どすなあ」 → 客が自分の腕時計を見る → 22:00に気づく → 客が自分から帰る。

## QA必須条件
- 全48シーンの中央フレームをQAシートに出す。
- 「壁に掛かった時計」「壁の時計」がナレーションに残っていたらProduction失敗。
- S02/S03/S06/S13/S15/S17/S19/S30/S47は腕時計モチーフで統一。
- 48 beats / 40+ distinct visual keys。
- 同じ和室会話構図を3シーン以上連続させない。
- 既存の青山龍星VOICEVOX、発音辞書、字幕同期、分割レンダー、ダークBGMを維持。
