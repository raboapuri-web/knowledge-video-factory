# プロローグ――貧乏であることの罰金

あなたは、貧しい人間ほど節約が上手でなければならないと思っているだろうか。収入が少ないのだから、安いものを選び、無駄遣いをやめ、身の丈に合った生活をするべきだと。

しかし、その正論には不思議な欠陥がある。この世界には、お金がある人ほど安く買うことができ、お金がない人ほど高く買わなければならないものが存在するのだ。

閉店間際のスーパーを想像してほしい。蛍光灯の下、仕事帰りの女性がトイレットペーパーの棚の前で立ち止まる。四ロール入りが三百二十円。十二ロール入りが七百二十円。前者は一ロール八十円、後者は六十円である。

どちらがお得なのか、計算するまでもない。十二ロールなら単価は二十五パーセント安くなる。節約を教える本なら、迷わず大容量を買えと助言するだろう。

しかし彼女の財布には五百円しかない。次の給料日まで数日あり、今夜の食事も買わなければならない。七百二十円の方が得だということを、彼女は十分に理解している。

それでも彼女が手に取るのは三百二十円の商品である。愚かな選択だろうか。計算が苦手なのだろうか。違う。彼女は割安な商品を選ぶためのお金を、持っていなかっただけなのだ。

余裕のある人は、今日七百二十円を払い、明日の支出を減らす。しかし余裕のない人は、今日三百二十円を払って、次回も高い単価を支払うことになる。

つまり、節約するためには、最初に節約できるだけのお金が必要なのである。ここに貧困のパラドックスがある。

イギリスでは、所得の低い世帯が生活必需品やサービスを利用する際、経済的な余裕のある世帯より余分な費用を負担する現象が研究されている。研究者はこれを、貧困プレミアムと呼ぶ。

プレミアムという言葉は普通、価値あるものに追加料金を支払う場面で使われる。しかしこちらは逆である。より良いサービスを買ったからではない。安い選択肢を利用できないという理由で、追加料金を支払うのだ。

今回は、貧しい人がいくら使うのかを笑う動画ではない。なぜ私たちの社会では、お金がないという事実が、さらにお金を失わせる仕組みになるのかを考えていこう。

# 第1章――安く買うためには金がいる

スーパーの棚に並ぶ商品の価格を、もう少し丁寧に見てみよう。洗剤、飲料水、米、保存の利く食品。大容量商品の単価が、小さな包装より安く設定されることは珍しくない。

もちろん、大量購入には欠点もある。使い切れず腐らせたり、保管場所がなかったりすれば、節約どころか無駄遣いになる。したがって、まとめ買いが常に正解だと言いたいわけではない。

それでも、確実に消費する日用品なら、購入量の違いが長期的な支出に影響する。そして、この単価の差を利用するには、目の前の支払いを行えるだけの現金が必要になる。

経済学には流動性制約という考え方がある。将来の利益が分かっていても、現在使える現金や借り入れ可能な資金が足りないために、望ましい投資ができない状態である。

一か月定期券の方が毎日の切符より安くても、購入日にまとまった金額を用意できなければ買えない。年払いの契約の方が得でも、その一年分を今すぐ払えなければ利用できない。

これらは未来の節約を、現在のお金で買っている行為である。現在の資金に余裕のある人ほど、将来の費用を減らす機会を多く持っている。

実際、アメリカの購買データを分析したマリック・ホサインの研究では、低所得世帯は高所得世帯より、単価の安いまとめ買いを利用しにくいという傾向が報告されている。

同じ店で買い物をしていても、購入する容量に差がある。低所得世帯がまとめ買いを利用できれば、対象とされた店舗支出をおよそ五パーセント節約できる可能性があると推計された。

ここで注意したいのは、この数字が日本人すべての食費を五パーセント減らせるという意味ではないことだ。特定の調査対象と条件に関する推計であり、国や生活環境が変われば結果も変わる。

さて、購入に必要なのは現金だけだろうか。大容量の米袋を抱えて持ち帰るための交通手段、まとめて保管する部屋、価格を比較するための情報もまた必要になる。

狭いワンルームで暮らし、自家用車を持たない人にとって、郊外の大型店で大量に買うという節約術は、簡単にまねできるものではない。

さらに視線を家電量販店へ移そう。二台の冷蔵庫が並んでいる。一台は購入価格が安いが電気料金は高め。もう一台は価格が高いが省エネルギー性能に優れている。

長期間使う場合、後者の方が総費用で安くなることがある。しかし故障した冷蔵庫を今日交換しなければならず、現金が足りなければ、高い方を選ぶ余地はない。

住居も同様である。断熱性能の高い住宅なら冷暖房費を抑えやすい。しかし家賃や入居審査が壁になれば、入居者は別の住宅を選ばざるを得ない。

賃貸住宅の住人は、将来の光熱費を節約するために建物を自由に改装することもできない。家賃を抑えた結果、別の支払いが増えるということも起こりうる。

一つひとつの行動は不合理ではない。むしろ予算の中では賢明な判断ですらある。だが、その判断が積み重なると、長期的な支払いで差が生じる。

お金のある人は節約できる。お金のない人は、節約に参加するための初期費用さえ払えない。この矛盾が日用品から住宅まで、さまざまなところに入り込んでいるのである。

# 第2章――お金がない人ほど、お金が高い

では、今は現金が足りなくても、借りて買えばよいのではないか。たしかに、信用によって現在と未来の支出を調整できれば、まとめ買いや必要な投資に参加しやすくなる。

しかし金融機関は、誰に対しても同じ金利でお金を貸しているわけではない。安定した収入があり、資産を保有し、返済履歴の良い人ほど、有利な条件で借りられる場合がある。

一方で、収入が不安定で資産が少なく、返済が滞る危険が高いと判断されれば、借り入れを断られたり、比較的高い金利を提示されたりする。

貸す側の視点に立てば、そこには合理性がある。返済されない危険に対して、価格を調整しなければ金融サービスを継続できないからだ。

しかし借り手の視点では、奇妙なことが起きる。お金を返す余裕のある人ほどお金を安く借りられ、余裕のない人ほどお金を高く借りることになる。

つまり、お金のない人間は、お金そのものの価格まで高くなるのである。

ここでイギリスの調査を見てみよう。ブリストル大学などの研究者が二〇二六年にまとめた報告では、調査対象の低所得世帯の九十五パーセントに、何らかの貧困プレミアムが生じていた。

その額は平均して年間三百八十ポンドと推計された。これは低所得者の総支出が富裕層より大きいという意味ではない。同様の必需品やサービスの利用に伴って生じる、余分な費用のことである。

その一例が自動車保険である。一年分を先に支払える人は追加費用を避けられる。一方、月払いを選ぶ必要がある人は、条件によっては分割に伴う費用を負担する。

同調査では、対象となった自動車保険の月払い利用者について、年平均七十一ポンドの追加費用が確認された。これは英国の市場と制度に関する調査であり、日本の平均額ではない。

ここに一枚の契約書があると想像しよう。同じ補償内容、同じ自動車、同じ運転者。違うのは、一年分を今払えるかどうかという点だけである。

ところが、一括払いを選べる人は安く済み、分割払いを選ぶ人は高くなる。収入の低さによって支払い方法が限られ、その支払い方法が追加の費用を生むのだ。

電気料金の支払い手段や高コストの信用サービスの利用にも、似た問題は存在する。もっとも、分割払いに伴う事務費用や信用リスクまで、すべて不当な利益と決めつけることはできない。

大切なのは、誰かが悪意で貧しい人をいじめているという話ではないことである。金融機関も保険会社も、自分たちの立場で合理的な価格を設定していることが多い。

それでも、多くの合理的な価格設定が集まると、最も余裕のない人間に最も高い費用が集中することがある。

さらに、一度の失業で貯金が尽き、生活のために借り入れを行い、返済が苦しくなるという状況を考えてほしい。返済実績が悪化すれば、次の資金調達はさらに難しくなるかもしれない。

条件が悪くなれば生活費の負担が増え、貯金を再建する余力が小さくなる。そしてその資産不足が、新たな不利な条件へとつながっていく。

もちろん、返済能力を無視して無制限に貸し付ければ解決するわけではない。危険な融資は借り手の生活をさらに悪化させる可能性もある。

個々の商取引が合理的であることと、社会全体として望ましい結果が生まれることは同じではない。貧困プレミアムは、まさにそのずれを示している。

# 第3章――節約するには、考える余裕がいる

ここで、再びスーパーの女性を思い出してほしい。彼女が大容量の商品を選べなかった理由は、お金が足りなかったからだ。しかし財布に七百二十円があれば、必ず最適な商品を選べただろうか。

私たちは売り場で、単価だけを計算しているわけではない。残高を確認し、給料日を数え、今月の家賃と明日の交通費を思い浮かべながら買い物をしている。

もし家賃の引き落としが心配で、仕事も不安定なら、日用品の小さな値札を比較することは、目の前に押し寄せる数多くの問題の一つにすぎない。

心理学者エルダー・シャフィールや経済学者センディル・ムライナタンらは、経済的な欠乏が人間の認知的な働きにどのような影響を与えるのかを研究した。

二〇一三年に科学誌サイエンスに発表した研究では、低所得者が金銭的な問題を考えさせられたとき、認知課題の成績が低下することが報告されている。

また、インドのサトウキビ農家について、収穫前の資金的に苦しい時期と収穫後を比較し、課題の成績に違いが見られたことも示された。

こうした研究には、実験条件や解釈をめぐる議論もある。すべての貧しい人の認知能力が劣っているなどという意味では、もちろんない。

むしろ注目したいのは、因果関係が逆かもしれないという点である。判断力がないから貧しくなるのではなく、経済的な不安が、判断に使える注意を奪っている可能性がある。

想像してほしい。あなたは長時間働いて帰宅し、明日の電気代の支払いが気になっている。その夜、携帯電話の料金を見直せば年間数千円節約できるという案内が届く。

合理的な人なら比較表を読み、解約手数料を調べ、最安の契約を選ぶべきだろう。しかし、疲れ切った人間が複雑な契約書を読むためには、時間と集中力が必要だ。

節約には、見えない労力が必要なのである。情報を探す時間、失敗を避ける注意、そして結果がすぐには現れない作業を続ける余裕である。

この負担は、行政の支援制度にも現れる。支援の資格があることと、実際に支援を受けられることは同じではない。

アメリカの食料支援制度を対象とした実験では、申請面接を受けやすいよう手続きを柔軟にすることで、給付の承認率が六パーセントポイント上昇した。

制度の所得条件自体を緩めたからではなく、手続きの負担を変えることで実際に支援に到達できる人の割合が変わったのである。

申請するには、制度を知り、必要な書類を揃え、決められた時間を使い、場合によっては何度も連絡しなければならない。最も支援を必要とする人ほど、こうした資源に乏しいことがある。

もちろん、審査は不正を防ぎ、財源を公平に配分するためにも必要である。しかし、必要な審査と不必要に複雑な手続きは同じではない。

生活を改善するためには、生活を改善するだけの時間と余裕が必要になる。ここでも、合理的に行動せよという助言が、簡単には実行できない条件に突き当たる。

# 第4章――合理的に生きるほど、抜け出せなくなる

ここまで紹介した現象には、一つの共通点がある。現在の資産が足りないことで将来の支出が増え、将来の支出が増えることで現在の資産を蓄積しにくくなるという循環だ。

経済学では、こうした自己強化的な仕組みを考えるとき、貧困の罠という概念が使われる。ただし、すべての貧困が単一の罠によって説明できるわけではない。

ここで、低賃金の仕事を続けている男性を想像してほしい。毎朝六時に起き、満員電車で職場へ通う。働いても貯金はほとんど増えず、将来の昇給も期待できない。

友人は言う。もっと条件の良い会社へ転職すればいい。資格を取ればいい。引っ越せばいい。それは、決して間違った助言ではない。

しかし面接に行くには時間がいる。資格取得には受講料がかかる。引っ越しには初期費用がかかる。退職から次の給与まで、生活費を賄う資金も必要だ。

貯金のある人にとって、それらは将来に向けた投資である。しかし毎月の生活がぎりぎりの人間にとって、失敗すれば家賃を払えなくなる危険な賭けになってしまう。

だから彼は今の仕事を続ける。家賃を確実に払い、目の前の生活を守るためには、きわめて合理的な判断である。

しかし、その合理的な判断が、低所得から抜け出す機会を失わせることもある。現在の生活を守ろうとするほど、将来の生活を変えにくくなるのだ。

この仕組みを、努力不足という一言で説明できるだろうか。努力するための時間も、お金も、失敗したときの安全網も、誰もが同じように持っているわけではない。

この点を考えるうえで、現金給付に関する実証研究は興味深い。経済学者ヨハネス・ハウスホーファーとジェレミー・シャピロらは、ケニアの低所得世帯に対する無条件現金給付を検証した。

研究では、給付を受けた世帯で消費や資産保有などの改善が観察された。まとまった現金を得ることで、それまで実行しにくかった投資が可能になる場合もある。

ただし、これはケニアの特定地域で実施された研究だ。同じ政策が日本でも同じ効果を生むと保証するものではないし、現金さえ渡せばすべての問題が解決するわけでもない。

それでも、まとまった資金を得るという行為は、単に財布の中身を増やすだけではない。それまで選べなかった選択肢を、初めて選べるようにする可能性がある。

私たちは貧困対策と聞くと、しばしば本人の行動を変えようとする。金融知識を身につけよ。計画的に暮らせ。もっと働け。もっと挑戦しろ。

しかし、適切な行動を取るための資源が最初から存在しなければ、説教だけでは解決しない。泳ぎ方を教える前に、足の重りを外さなければならない場合もある。

もちろん浪費や不注意によって経済的に困窮することもあるだろう。しかし一人の失敗を説明することと、社会全体で貧困が再生産される構造を説明することは別の問題である。

重要なのは、給付をするかしないかという二択に閉じ込めないことである。必要なサービスの購入方法、契約の条件、制度へのアクセス、転職に必要な初期費用。改善できる場所はいくつもある。

貧困対策とは、誰かを永久に援助することだけを意味しない。自分の力で経済活動に参加するための条件を整えることも、貧困対策なのである。

# エピローグ――貧困とは、選択肢が高価な社会である

私たちは貧困を、収入が少なく、貯金が足りない状態だと考えている。それは間違いではない。しかし、お金は単に商品を購入するための道具ではない。

お金は、将来の支出を減らすための手段であり、失敗したときに生活を守る保険であり、より良い選択を実行するための自由でもある。

余裕のある人は、買い物で長期的な費用を考えられる。不利な契約を断ることができる。今の収入を一時的に手放して、将来への投資を行うこともできる。

しかし余裕のない人は、今日の生活を守るために明日の節約を諦めなければならない場合がある。現在の家賃を守るために、将来の収入を増やす機会を逃してしまう。

豊かな人間は未来を安く買うことができるが、貧しい人間は未来を高く買わなければならないのである。

もちろん、貧しい人の生活費が富裕層の総支出より高いという話ではない。特定の必需品やサービスで、同じようなものを手に入れるための単位費用や追加料金が高くなることがある、という話である。

その追加費用は、税金のように明確な名前で請求されるわけではない。小さな包装の割高な単価として、分割払いの追加費用として、不利な契約条件として積み重なる。

そして、いま選べなかった節約が、将来の選択肢をさらに狭めていく。貧困プレミアムとは、貧困に課せられた見えない罰金のようなものなのだ。

ここで最後に一つだけ考えてほしい。私たちは貧しい人に向かって、もっと合理的に選択しろ、もっと将来を考えろと、簡単に言う。

しかし合理的に生きるためにも最初にお金が必要であり、未来を考えるためにも今日の生活を心配しなくてよい余裕が必要なのだとしたら。

私たちが自己責任と呼んできたものの中には、本人の努力以前に与えられた選択肢の違いが含まれているのではないだろうか。

貧困とは単にお金を持っていない状態なのではない。お金を持っていないという理由によって、人生のさまざまな選択に、追加料金が発生してしまう状態なのである。
