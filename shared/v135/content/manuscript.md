# プロローグ：死んだはずの神々が復活する

これはクライムノベルではない。

カルトノベルである。

かつてキリスト教によって侵略され、歴史の闇に葬られたアステカの神々。

しかし、神々は死んでいなかった。

五百年もの間、地底で息を潜め、再び人間の心臓を喰らう日を待ち続けていたのである。

そして現代。

神々は新たな肉体を手に入れた。

ドラッグ・キャピタリズム。

ブラッド・キャピタリズム。

もはや神々に巨大なピラミッドも、黒曜石の祭壇も必要ない。麻薬の流通網が血管となり、臓器売買の手術台が祭壇となる。

資本主義という巨大な怪物に寄生した古代の神々が、今まさに現代社会の腸を食いちぎろうとしている。

佐藤究の『テスカトリポカ』。

物語は、メキシコの巨大麻薬カルテルを率いていたバルミロ・カサソラが、敵対組織との抗争に敗れ、祖国を追われるところから大きく動き始める。

兄弟も家族も失ったバルミロは、逃亡先のインドネシアで日本人の臓器ブローカー、末永と出会う。二人が目をつけたのは、日本で行方の見えなくなった子どもたちを集め、その心臓を富裕層に売り渡すという商売だった。

そして舞台はメキシコからジャカルタへ、そして日本の川崎へと移っていく。

そこに登場するのが、土方コシモという少年である。

暴力の中に生まれ、暴力によって両親を失い、やがて古代アステカの神々を信じる男に拾われた少年。

コシモの人生を追いかけているうちに、読者は一つの奇妙な事実に気づくことになる。

五百年前に滅んだはずの宗教が、現代社会を動かしている。

そして、その宗教を再び葬ることになるのも、かつてアステカの神々を征服したキリスト教なのではないか、ということである。

# 第1章：コシモの少年時代

この小説の主人公の一人は「コシモ」という少年である。

兄を麻薬組織に殺されたことから、麻薬密売人を憎むコシモの母、ルシアはメキシコで生まれ育った。

自分の家族を破壊したものから逃れるため、彼女は故郷を離れ、日本へとたどり着く。

そこで出会ったのが、後にコシモの父親となる土方興三であった。

土方は川崎の暴力団幹部である。ルシアは彼との間に子どもをもうけ、コシモと名付けた。

しかし、そこに幸福な家庭など存在しなかった。

父親は暴力を振るう男だった。やがて暴力団を取り巻く環境が厳しくなると、土方の生活も行き詰まり、家に帰ることすら少なくなっていく。

一方、母親の生活は次第に荒んでいった。

そして彼女は、あれほど憎んでいたはずの麻薬に手を出し始める。

もっとも、それは兄を殺したメキシコのカルテルが扱うコカインとは違う。自分が使っているのは覚醒剤、ICEなのだから、あの連中の商売とは別物だ。

彼女の中には、そんな都合のよい区別があった。

もちろん、そんな理屈で何かが変わるわけではない。彼女が憎んでいたのは麻薬によって人間の生活が破壊される世界だったはずなのに、いつの間にか自分自身がその世界の一部になっていたのである。

人間は自分が嫌悪するものから逃れようとする。しかし、嫌悪するものと自分自身がまったく無関係であると、どうして言い切れるのだろう。

その矛盾を、まだ幼いコシモは一身に引き受けることになる。

父親は帰ってこない。母親は薬物に溺れている。

学校教育もまともに受けられず、十分な言葉も身につかないまま、コシモの身体だけは異様な速度で成長していく。

彼には、生まれつき並外れた腕力があった。

しかし、コシモは乱暴なだけの少年ではない。

彼は父親が家に持ち込んだ小刀を使い、木の枝から小鳥の彫刻を作ることを好んでいた。

人間の身体を傷つけるための刃物を使って、小さな鳥を彫り出す。

この何気ない描写はコシモの純真無垢さを最大限表現していると思う。

コシモは暴力と隣り合わせの環境で育ちながら、その暴力の道具を使って何かを創造することができた。

刃物は人を殺すこともできる。しかし、鳥を生み出すこともできる。

同じ道具を手にしていても、人間が何をするかは決まっていないのである。

ところが、コシモには決定的に欠けているものがあった。

自分の持つ力が、他人の身体に何をもたらすのかを理解するための教育と経験である。

そして十三歳のとき、事件が起きる。

久しぶりに家へ帰ってきた父親と衝突したコシモは、自らの並外れた腕力によって父親を死なせてしまう。

さらに、目の前の出来事に錯乱した母親も、コシモとの衝突の末に命を落とす。

両親を殺した少年。

社会は当然、この事実によってコシモを評価することになる。

しかし、少し考えてみてほしい。

十分な教育も受けられず、まともな愛情も与えられず、暴力を日常として育った少年に、我々はどのような倫理を期待しているのだろうか。

生まれてから一度も教わったことのない規則を破った人間に、どうしてその規則を知らなかったのかと問い詰めるようなものである。

もちろん、過酷な環境で育ったことが殺人の免罪符になるわけではない。

しかし、コシモの行動を単に「異常な少年による凶悪犯罪」と片づけてしまうなら、我々は彼の人生から何一つ学ぶことができないだろう。

コシモは少年院へ送られる。

そして、彼が社会に戻ったとき、その才能に目をつけた二人の男が現れる。

この二人との出会いこそが、物語を単なる犯罪小説から宗教的な寓話へと変えていくのである。

# 第2章：コシモと二人の父親

コシモは実の父親を殺した後、二人の父親的存在と出会う。

一人は、メキシコの麻薬密売人バルミロ・カサソラ。

もう一人は、ナイフ職人の座波パブロである。

この二人は、コシモにまったく異なる世界を教えることになる。

バルミロは、コシモの並外れた身体能力に価値を見いだした。

かつてメキシコの巨大カルテルに君臨していた彼は、組織の抗争によって兄弟も家族も失っていた。そんな彼にとって、圧倒的な力を持つコシモは、新たな家族として迎え入れるにふさわしい存在だった。

バルミロはコシモを息子のように扱い、彼に一族の信仰を教え始める。

アステカの神々。

かつて人間の心臓を要求し、人々の運命を支配していた古代の存在である。

バルミロ自身もまた、祖母リベルタからその神話を聞かされて育った。

つまり、彼がコシモに行ったのは単なる洗脳ではない。自分が幼い頃に受け継いだ世界観を、次の世代へと継承する行為だった。

親が子に宗教を教えること自体は、何も珍しくない。

キリスト教徒の親は子どもに聖書を教え、仏教徒の家庭では仏壇に手を合わせることを教える。自分の信じる世界観を次の世代へ伝えるのは、人類が繰り返してきた営みである。

では、バルミロがコシモにアステカ宗教を教えることの何が問題だったのか。

その答えは、アステカの信仰が他者の犠牲を要求する形で実践されていたことにある。

古代アステカでは神々は自ら命を賭して太陽に再び輝きを取り戻したとされている。

それ以来、人類は神々に「命の借金」をしている。

だからこそアステカ古代宗教では太陽を動かし続けるために贄を捧げ続ける必要があるのだ。

バルミロにとっても、人間の身体は神々に捧げることのできる供物だった。そして同時に、金銭と交換することのできる商品でもあった。

古代宗教と現代資本主義。

まるで無関係に見える二つの価値観が、バルミロという一人の人間の中で矛盾なく共存している。

一方のパブロは、コシモに刃物を作る技術を教えた。

彼はナイフ職人である。

バルミロがコシモの腕力を評価したのに対して、パブロはその器用な手先に価値を見いだした。

どちらもコシモの才能を認めていた。しかし、二人がその才能に求めたものは違っていた。

バルミロは、人を殺せる力を求めた。

パブロは、ものを作れる力を育てた。

もちろん、パブロも完全な善人ではない。彼自身、犯罪組織との関係から自由ではなく、良心と保身の間で揺れ動いていた。

それでも、彼はコシモに別の生き方の可能性を示したのである。

考えてみれば、実の父親が家に持ち込んだ小刀で小鳥を彫っていた少年が、やがてナイフ職人から技術を教わるという展開には、何か運命めいたものがある。

人を殺すための刃物から、ものを生み出すための刃物へ。

コシモの人生には、最初から二つの可能性が存在していたのだ。

そして、この二人の父親を決定的に分けるものが、もう一つあった。

それは宗教である。

バルミロがコシモに古代アステカの神々を教えたのに対し、パブロは父親から受け継いだ聖書の言葉を通じて、まったく異なる倫理を伝える。

この時点でコシモは、まだ自分がどれほど巨大な宗教的対立の中心に立たされているのか、理解していなかっただろう。

しかし、読者はここから五百年前の歴史を思い出さなければならない。

なぜなら、この二人の父親がコシモに伝えようとした価値観は、かつてメキシコの大地で衝突した二つの宗教を思い起こさせるからである。

# 第3章：アステカ古代宗教とキリスト教

十六世紀、現在のメキシコに栄えていたアステカ帝国は、スペイン人を中心とする征服軍と、それに協力した先住民勢力によって滅ぼされた。

一五二一年、首都テノチティトランが陥落する。

その後、スペインによる植民地支配が始まり、キリスト教の布教とともに、アステカの宗教的秩序は大きく変えられていった。

この歴史を単に「野蛮な宗教が文明的な宗教に取って代わられた」と理解しているなら、ずいぶん都合のよい歴史観を持っていると言わざるを得ない。

アステカの人身供犠が現代人にとって残酷な行為であることは疑いようがない。

しかし、それがアステカの歴史観であり根源だったのだ。

スペインの征服事業には宗教だけでなく、権力、富、領土といった目的が絡んでいた。キリスト教の布教が、常に慈悲深い平和的な営みだったわけでもない。

そして、アステカの神々は滅亡した帝国とともに完全に消え去ったわけではなかった。

先住民の信仰は姿を変え、ときにはキリスト教と混ざり合いながら生き残った。

『テスカトリポカ』に登場するバルミロの祖母リベルタは、そうした古代の記憶を受け継ぐ存在として描かれている。

バルミロは、その祖母から受け継いだ神々を、現代によみがえらせようとしていた。

そして彼は、まさにそのために必要な力を手に入れていた。

<心臓・資本主義>コラソン・キャピタリズムである。

かつてアステカでは、神々と世界の秩序を維持するために人間の心臓が捧げられていた。

現代の臓器密売では、富裕層の命を延ばすために、貧しい人間や保護されるべき子どもの心臓が犠牲にされる。

古代では神が心臓を求めた。

現代では市場が心臓を求める。

そして驚くべきことに、後者には信仰すら必要ない。

誰も神を信じなくても、誰かの命に値札をつける仕組みは成立するのである。

現代感覚では古代アステカの人身供犠を野蛮だと感じるだろう。

しかし、現代社会が生み出した臓器密売の仕組みを見れば、野蛮さの本質が本当に克服されたのか疑わしくなってくる。

さて、ここでコシモの物語に戻ろう。

バルミロから古代の神々を教えられたコシモは、組織が抱える少年、順太と出会う。

順太は、心臓を売るために集められた子どもの一人だった。

コシモは彼と交流を重ねる中で、友人としての感情を育てていく。

そして順太は、コシモが教わった神話に思いがけない解釈を与える。

それまで神秘的な存在として語られていた「煙を吐く鏡」のイメージを、順太は日食という自然現象と結びつけたのである。

コシモにとって、それは小さくない衝撃だったはずだ。

自分が父親として慕っていたバルミロは、世界のすべてを知っているわけではなかった。

古代の神々について何も知らないはずの少年が、バルミロとは違う説明を与えられる。

宗教的権威に亀裂が入る瞬間である。

しかし、さらに決定的なのが、パブロから伝えられた聖書の思想だった。

マタイによる福音書には、次のような言葉が登場する。

「わたしが求めるのは憐れみであって、いけにえではない」

これは作中で描かれるアステカの人身供犠と、あまりにも鮮やかな対照をなしている。

神に捧げるために人を殺す。

人を憐れむために生贄を拒む。

二つの宗教的価値観が、ここで真っ向からぶつかるのである。

そして物語の終盤、コシモは順太を救うために、自分が父親として慕ってきたバルミロと敵対することになる。

最後にコシモは、バルミロを殺す。

私はこの結末を読んだとき、一つの歴史的な反復を感じずにはいられなかった。

アステカの神々は、再びキリスト教によって殺されたのではないか。

五百年前、スペインによる征服とキリスト教化の中で、アステカの宗教的秩序は破壊された。

そして五百年後、キリスト教的な慈悲の思想に触れたコシモによって、アステカの神々を復活させようとしたバルミロが殺される。

一度目は、征服者が外からやってきた。

二度目は、神々の信仰を継承するはずだった少年が、その信仰を内側から否定した。

もちろん、コシモがキリスト教に改宗したわけではないし、バルミロを殺した直接の理由は順太を救うためである。

だからこれは、宗教的な動機による殺人だったという主張ではない。

しかし、物語の構造を宗教史に重ねてみるなら、これほど皮肉な結末もないだろう。

神々を復活させようとした男が、かつてその神々を征服した宗教の倫理に触れた少年によって殺されるのである。

そして、生贄を否定するはずの思想に導かれた少年もまた、最後には人を殺すことになったのだ。

# 第4章：人間は暴力から逃げられない。それは宗教でも社会でも

人間は進歩した。

我々はそう信じたがる。

古代の人身供犠は廃止され、宗教的な迷信から解放され、法律と人権によって秩序を維持する社会が誕生した。

たしかに、歴史を通じて人間社会が変化し、暴力を制限するための制度を発展させてきたことは否定できない。

しかし、それを理由に、現代人が古代人よりも本質的に善良になったと考えるのは早計である。

『テスカトリポカ』で描かれるのは、文明が高度になるにつれて暴力もまた洗練されていくという不気味な現実だ。

古代の神官は、人間の心臓を神々へ捧げた。

現代の臓器密売人は、人間の心臓を富裕層へ売り渡す。

前者は宗教儀式であり、後者は経済取引である。両者をまったく同一のものとして扱うことはできない。

しかし、そこには確かに共通する構造がある。

ある人間の利益や救済のために、別の人間が犠牲にされるという構造である。

古代の人々は神々を信じることで、この犠牲に意味を与えていた。

現代の犯罪者たちは金銭を手にすることで、同じような犠牲を正当化している。

そう、それはまるで鏡合わせだ。

神々が要求した生贄を、現代の市場は商品として流通させることができるのだ。

そして、暴力の問題は宗教同士の対立にも表れている。

十六世紀、スペイン人たちはキリスト教を掲げながらアステカ帝国を武力で征服した。

現代人から見れば残酷な人身供犠を行っていた宗教を、やはり暴力によって屈服させたのである。

そして本作の結末では、パブロからキリストの慈悲の思想を受け取ったコシモが、友人を守るためにバルミロを殺した。

これも、また鏡合わせのように。

コシモは暴力を否定するために、暴力を選ばなければならなかった。

思い出してほしい。

コシモは幼い頃、自分に暴力を振るう実の父親を殺している。

そして成長した彼は、自分が父親として慕っていたバルミロも殺すことになる。

最初の父親は身体的な暴力によってコシモを支配しようとした。

二人目の父親は、信仰と家族という言葉によってコシモを支配していた。

そのどちらからも、コシモは殺人によってしか逃れることができなかった。

しかし、これを単なる暴力の連鎖として片づけてしまうのも違うと思う。

物語の最初、コシモは自分の腕力が何をもたらすのか十分に理解していなかった。

しかし最後のコシモは違う。

彼には守りたい存在がいた。

順太という友人がいた。

そして、自分の意思でその友人を守ろうとした。

暴力という結果は似ていても、その内側にある意思は変化している。

コシモは暴力から逃れられなかった。しかし、暴力に意味を与える存在を、神々から自分自身へと取り戻したとも言えるのではないだろうか。

それは決して幸福な結末ではない。

救済のために人を殺さなければならない世界を、幸福だと呼ぶことはできない。

それでも、他者を犠牲にすることを当然とする世界から、目の前の一人を犠牲にさせないために抵抗する世界へと、コシモは踏み出したのである。

そして私は、この物語の題名に立ち返りたくなる。

テスカトリポカ。

煙を吐く鏡。

古代アステカの神の名である。

鏡というものは、自分の姿を映し出す。

読者は古代アステカの人身供犠やコラソン・キャピタリズムの前に、なんと残酷で野蛮だろうと顔をしかめる。

しかし、本書「テスカトリポカ」という鏡に映っているのは、ほかでもない、あなた自身ではないだろうか。

誰かが犠牲になることで成り立つ豊かさを享受しながら、自分たちはもう生贄など必要としない文明人なのだと信じている。

自分の信じる正義を守るためなら、他者に暴力を振るうことさえ正当化できる。

我々が古代アステカの人々やコラソン・キャピタリズムを敬遠する資格は、いったいどこにあるのだろう。

もちろん、現代社会のあらゆる経済活動を人身供犠と同一視するつもりはないし、文明が積み重ねてきた人権や制度の発展を否定するつもりもない。

しかし、だからこそ考えなければならない。

制度が進歩したことと、人間が暴力から解放されたことは、同じではないのである。

バルミロは死んだ。

コシモは彼の信仰から離れ、順太は犠牲になることを免れた。

それでも、世界から暴力が消えたわけではない。

バルミロを殺したところで、別の場所で麻薬は売られ、人間の身体は商品にされ、誰かが誰かの利益のために犠牲にされているかもしれない。

古代の祭壇は失われた。

神官たちの姿も消えた。

しかし、犠牲を要求する人間の欲望は、時代に合わせて名前と姿を変えていく。

もしかすると、アステカの神々は一度も復活していないのかもしれない。

なぜなら、一度も死んでいなかったのだから。
