# V139 — チーム人数のパラドックス | 考える夜 本番映像

タイトル：なぜチームの人数を増やすほど、仕事が遅くなるのか？

Motion Canvasで、**原稿そのままのナレーション**を6章に分割し、VOICEVOX 青山龍星ノーマル（speakerId 13 / speedScale 1.15）で実測音声尺と字幕を同期する。本編は1920×1080 / 30fps / H.264 + AAC、BGMつき。

`content/manuscript.md` にナレーションを全文保持。 `scripts/compile.py` が句読点を基準に意味ビートを切り出して `content/scenes.json` と章ごとのMotion Canvasプロジェクトを生成する。描画本体は `src/lib/director.tsx`。章ごとに個別レンダリングして結合する。

**表現ルール**：情景描写を無理に再現せず、人数のネットワークグラフ、アムダールの法則の積み上げ、LEGO実験の延べ労働時間、リンゲルマンの綱引き、社会的手抜きの棒グラフ、災害マッピング、メタ分析、承認待ちの依存関係を、各専用のベクター図解として制作。隣接するシーンで同じ視覚文法は連続しない。字幕レイヤーが必ず最後・最前面。

最終作品はGitHub Actions `V139 Team Size Paradox Motion Canvas` が生成し、章MP4、統合MP4、QA記録、コンタクトシートをArtifact/Releaseへ保存する。VOICＥVOXの実音声が生成されるまで尺は確定しない。

修正する際は該当章を単位として再レンダリングする設計。なお全章完成後の自動結合／QAが必要となる。

注意：実験の指標は厳密に区別する。LEGOの「72対112人・分」は延べ労働量であり、実時間において4人チームが遅いとは主張しない。メタ分析はチーム成果と規模の関連であって時間の直接測定ではない。
