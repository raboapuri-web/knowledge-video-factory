# V115 — Motion Canvas Production

Production implementation for 「なぜ会社では『成果』より『感じの良さ』が出世を決めるのか？」.

This is the first full-length production using the Motion Canvas approach validated by the V114 prototype.

Core design:
- 42 semantic beats rather than hundreds of sentence-level cuts.
- Six independent chapter projects.
- Continuous state changes inside each beat.
- Parallel VOICEVOX and chapter rendering.
- Fully headless GitHub Actions rendering.
- Only representative frames are intended for human visual review.
