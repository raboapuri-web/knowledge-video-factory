## 2. 制作概要

- スライド方式・エフェクト付きで制作する。
- スライド総数：64枚（各画面に固有のアートディレクションを設定）。
- 構成：プロローグ＋第1章〜第4章＋エピローグの6章。
- 想定総尺：1,609秒（約26分49秒）。
- 章別枚数：プロローグ5枚／第1章12枚／第2章13枚／第3章15枚／第4章15枚／エピローグ4枚。
- ナレーションは承認済みの6本のテキストファイルを正本とし、加筆・削除・要約・言い換えをしない。
- 章タイトルは画面表示用であり、ナレーションとして読み上げない。
- 台本の尺に映像を無理に合わせて文章を編集せず、ナレーションとスライドの同期で調整する。

## 5. タイポグラフィ・画面設計

- 日本語フォントは明朝体を基本とする（Noto Serif CJK JPを想定）。
- 見出しは太めの明朝体、本文は読みやすい明朝体。
- 画面の文字量を抑え、重要語・数字・対比を大きく表示する。
- 組織ピラミッド、昇進階層、社員配置、営業成績比較、管理職適性、抽選箱、評価制度、キャリア分岐、因果関係図などを使用する。
- 64画面の個別演出：`content/art-direction.json`、新規専用Motion Canvasエンジン：`src/lib/promotion.tsx`。旧版の別動画汎用描画処理は使用しない。
- スライドはナレーションの意味を補助する。ナレーションを画面に全文表示する必要はない。

## 6. エフェクト方針

- フェード、スライドイン、ズーム、カウントアップ、スタガー、パン、図解構築を使い分ける。
- 同じエフェクトを機械的に連続使用しない。抽選・組織階層・能力比較・トーナメント・実験モデル等、意味と一致した図解動作を用意する。
- 動きはゆっくりとし、ナレーションや画面上の文字を読む妨げにしない。
- 図表は要素・線・数値を段階的に表示し、視線誘導を明確にする。

## 7. BGM仕様

- 既存BGM・他動画の音源・外部音源を使用せず、Node.js標準ライブラリで完全新規に手続き合成する。
- 生成スクリプト：`shared/v151/scripts/gen-bgm.mjs`。
- 出力既定値：`shared/v151/bgm/ambient-v151.wav`。
- 音源長：120秒。
- 形式：44.1kHz／16bit PCM／ステレオWAV。
- 音色：サイン波を重ねたゆっくりしたパッド＋静かなアルペジオ。
- オリジナルコード進行：Dm(add9) – Bbmaj7 – F(add9) – Csus2 を基調とする。
- 音量はナレーション優先で控えめにする。フェードイン・フェードアウトを入れる。
- 120秒素材を約26分49秒の本編に使用する際は、継ぎ目が目立たないようループまたは反復配置し、最終尺でフェードアウトする。単純に120秒でBGMを終了させない。

## 9. スクリプトの役割

- `scripts/compile.mjs`：6本のナレーションと64枚のslides.jsonを検証・正規化し、`content/slides.json` と `content/audit.json` を生成する。章名引数がある場合は `content/slides-<章名>.json` を生成する。
- `scripts/synth.mjs`：VOICEVOX APIの `/audio_query` と `/synthesis` を使い、指定章のナレーションを文単位で合成して `audio/<章名>.wav` と `audio/speech-timing.json` を生成する。
- `scripts/gen-bgm.mjs`：v151専用のオリジナルアンビエントWAVを手続き合成する。
- `.github/workflows/v151-promotion-lottery-slides.yml`：storyboard → 6章マトリクス → finalize → GitHub Release の順に実行する。

## 10. 検証・禁止事項

1. ナレーション6本の全文を一字一句変更せずに使う。加筆・削除・要約・言い換えは禁止。
2. 章タイトルは読み上げない。
3. スライド総数は64枚、章別枚数は5／12／13／15／15／4。
4. 想定総尺は1,609秒。実際の音声長はVOICEVOXの実測値を記録し、映像同期に反映する。
5. 各スライドの `narration` は、章内ナレーションの `start` / `end` 文字位置と完全一致し、欠落・重複・順序変更がないこと。
6. `start` は章内文字位置、`end` は排他的な終端位置とする。
7. 禁止語「有性生殖」「無性生殖」をスライド文言・メタデータに含めない。
8. 画面文言は昇進・くじ引き・組織論・人事経済学・評価制度・キャリア等、本動画のテーマに関係する語に限定する。
9. 他行のプロジェクトコード、テンプレート、ナレーション、スライド内容、BGM、素材をコピー・クローン・流用しない。v151は独立した新規プロジェクトとする。
10. 有料アップグレードを行わず、GitHub Actions無料枠で制作する。
11. BGM生成に失敗した場合はナレーションを優先し、BGMなしでも最終動画を完成できる構成にする。
