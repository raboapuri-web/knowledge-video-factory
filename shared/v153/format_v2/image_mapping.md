# V153 章カード画像対応表

画像生成の表示順での対応は以下のとおり。

1. 共通ベース画像 — 予備／全章のスタイル参照。章カードには直接使わない。
2. プロローグ — `prologue_bg.png`
3. 第1章 — `chapter1_bg.png`
4. 第2章 — `chapter2_bg.png`
5. 第3章 — `chapter3_bg.png`
6. 第4章 — `chapter4_bg.png`
7. エピローグ — `epilogue_bg.png`

6枚の章別画像は1920×1080へ整形して配置する。1枚目のベース画像は、章別画像のトーンが崩れた際の参照用。
