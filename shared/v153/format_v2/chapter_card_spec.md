# V153 章カード仕様（format v2）

## 対象
「なぜ深海の生き物は巨大化するのか？」の6パート（プロローグ／第1章〜第4章／エピローグ）。章タイトルはVOICEVOXの読み上げ対象から除外し、カード映像上だけで表示する。

## 画面・背景
- 1920×1080、30fps、16:9。
- 章ごとに背景画像を1枚使用。6枚で色調・月のキャラクター・構図の世界観を統一する。
- 背景はごく緩い2%ズームイン。派手なトランジションは使用しない。
- 文字は画面中央より右（中心X=1220px）に置き、左側の月キャラクターを隠さない。
- 画面下部130pxは字幕帯のための予約領域。章カードでは字幕を表示しないが、黒帯は同じ位置に敷く。

## タイピング
- 速度：9文字／秒（仕様上の許容目安は8〜10文字／秒）。
- 表示順：章ラベル → 0.15秒の間 → 章タイトル。
- 開始前に0.25秒の背景見せを置く。
- カーソル：`▌`。全文表示後0.6秒間、2Hzで点滅させ、その後は消す。
- カード末尾：カーソル消灯後、完成したタイトルを1.0秒静止表示。
- 総尺：最低4.0秒。実際の文字数に応じて「タイピング時間＋カーソル点滅0.6秒＋静止1.0秒」を確保し、約4.0〜4.8秒とする。

## 文字位置・書体
- 書体：Noto Sans CJK JP（GitHub Actionsの既存 `install_media_tools.sh` が導入するフォント）。
- 章ラベル：44px、中心X=1220px、中心Y=405px、落ち着いた金色。
- 章タイトル：66pxを基準に、最大幅1320pxに収まるまで56pxまで縮小。中心X=1220px、中心Y=520px、生成り色。
- 縁取り：濃い金色、2px。影：黒、右下3×4px。
- 文字は背景に焼き込まず、レンダリング時に透明オーバーレイとして合成する。

## タイピング音
- `audio/type_key.wav` を使用し、1文字ごとに1回鳴らす。
- 1文字あたりの音量ゲインは0.45。章カードの音声は打鍵音のみで、ナレーション・BGMは入れない。
- WAVは48kHz／16-bit／mono。章動画と本編シーン動画も48kHz mono AACに統一する。

## 字幕帯
- x=0、y=950、幅1920px、高さ130px。
- 不透明な黒。映像より前、字幕より後ろの独立レイヤーとして描画する。
- 字幕文字は帯内の中央。ASS字幕の下マージンは24pxに設定する。

- `assets/chapter_cards/backgrounds/chapter1_bg.png`
