# 『なぜ深海の生き物は巨大化するのか？』全編画面設計
## 設計概要
- **画面数：88画面（S001〜S088）**
- **画面尺の目安：平均15秒前後**。台本の音声実尺に合わせ、短い画面は前後の画面と調整する。
- **素材内訳：収集78画面／生成10画面**。生成は現象の仕組みを示す模式図・概念図に限定し、生物の写真風画像は生成しない。
- **表示要素：関連画像＋字幕のみ**。章名・説明テキスト・図表タイトルなどを画像に焼き込まず、必要な情報は台本字幕で伝える。
- **画像の動き：** 1枚の画像を画面いっぱいに置き、5〜7%程度のゆっくりしたズームまたはパンを基本とする。急な拡大縮小、派手なトランジション、画像内の不要な装飾は使わない。
- **映像資料の扱い：** NOAA等の動画資料は、必要な場面の高画質フレームを静止画として切り出し、同じくゆっくりズーム／パンで見せる。動画をそのまま再生する前提にはしない。
- **台本原文：** 下記コードブロック内は添付台本の非空行を順序どおりに配置。語句・数字・固有名詞・句読点は変更していない。

## 素材入手先・権利確認の共通ルール
- NOAA Ocean Exploration / NOAA Ocean Serviceのページは、写真・映像のダウンロードリンクやクレジット表記を個別に確認する。NOAA名義であっても一律に権利条件を推定せず、各素材ページの表記を優先する。
- Wikimedia Commonsは、カテゴリページから使うファイルを選び、**ファイルごとにライセンス、作者、クレジット、改変条件**を確認する。
- Nautilus Live / Ocean Exploration Trustの映像は、公開ページがあることと再利用許諾があることを同一視しない。利用条件・問い合わせ先・クレジットを確認する。
- BMC Biologyの2022年論文はオープンアクセス（CC BY 4.0）。ただし論文内の図版に第三者素材の例外表記がないか、各図のクレジットを確認する。
- Natureの1999年論文は研究内容の参照先として扱い、論文図をそのまま転載する場合は別途権利確認を行う。今回の研究説明画面は、数値を捏造しない独自の概念図として設計する。
