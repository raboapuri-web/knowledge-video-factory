# V119 「ホームレス」を放置すると街全体が貧しくなる理由｜考える夜

V118で安定した最新Motion Canvas制作方式を継承し、都市を一つの因果システムとして描く。

- 8章 / 38意味シーン。文章ごとの独立カット量産ではなく、1意味空間の中で4段階以上の因果変化を進める。
- 青山龍星ノーマル、VOICEVOX speaker 13、speedScale 1.15。
- VOICEVOX実測後に各章の尺を確定し、字幕も実音声タイミングへ置換する。
- 字幕は最前面の独立overlay。映像オブジェクトが字幕へ侵入しない。
- 各意味シーンは固有motifを持ち、隣接シーンで同一motifを使わない。
- 章別smoke renderを通過した章だけ本番レンダーする。
- 完成章MP4をReleaseへ保持し、章単位再レンダーを可能にする。
- final QA: 1920×1080 / 30fps / audio / duration / blackdetect / freezedetect / contact sheet。

## 映像設計
ホームレスの人を「街を汚す存在」として描かず、住宅機能が公共空間へ外部化される過程を中心に描く。スーパー、駅、公園、警察、病院、中心街、Housing Firstの部屋を、因果で接続された都市システムとして見せる。
