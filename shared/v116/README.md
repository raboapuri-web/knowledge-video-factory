# V116 — Motion Canvas production

## なぜ人間は「自分らしさ」に殺されるのか？
### 自己像×アイデンティティ×後方互換性

This build contains 40 semantic Motion Canvas scenes across 9 independently renderable chapters.

The dominant visual systems are:
- the public persona becoming larger than the person;
- self-story and identity-verification loops;
- audience expectation / creator feedback;
- software backward-compatibility and dependency graphs;
- fixed-self cage versus versioned/updateable self.

The design deliberately avoids generic “person + icon” repetition.
