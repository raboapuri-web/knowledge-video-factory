# 資本主義動画：アニメーション・スライド方式 検証版

## 方式
- 対象: 「資本主義は人類最高の発明か」台本より代表的な5論点、15ナレーションビート
- 1920×1080 / 30fps、Motion Canvas 3.17.2
- 文章の途中で頻繁に背景カットを変えず、論点ごとに1スライドを保持
- スライド内は専用の図表／数値／対比のアニメーション（映像の意味が変わるときだけ動く）
- VOICEVOX 青山龍星、音声の実測時間に合わせてアニメーションを構成
- 字幕は本文を省略しない逐語字幕。下部固定、画面構築の**最後**に描くので最前面
- 字幕セーフエリアは下 172px、スライド内で空ける。字幕は最大2行想定。
- キャプションをSRT風の別レイヤーとして後合成しないため上下関係が崩れない

## スライド内訳
1. 批判の三つのキーワード: 格差・搾取・環境破壊
2. 世界銀行の極度の貧困脱出人数（1990〜2022年 約15億人）
3. ケニアのJ-PAL研究（研修＋紹介群の月収 +37%）
4. 米国EPA（実質GDP +338%、主要大気汚染物質の排出量 −79%）
5. 結論: 理想郷でなく現実の代替案と比較する

## 注意
- ケニアの実験は**GAFA委託単独の因果効果を示さない**。
- EPAの「主要大気汚染物質」は**CO₂を含む地球温暖化ガス全体ではない**。
- 世界の貧困改善は**市場の因果効果を単独で証明するものではない**。

## レンダリング
この試作は `.github/workflows/capitalism-slide-pilot.yml` の Actions で
VOICEVOX → タイミング生成 → Motion Canvas → MP4 → QA → Release まで自動化する。

この実験ブランチは本番動画を上書きしない。採用判断後、元台本全体を
スライド設計／章別生成／毎秒の字幕計測へ拡張する。
