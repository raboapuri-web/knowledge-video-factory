# V40 Flynn Effect

Target: 15–20 minute long-form production.

Core thesis: The 20th-century Flynn effect is not simply evidence that humans evolved into a smarter species; it records how schooling, health, abstract-symbolic environments, work complexity, and test familiarity changed the kinds of cognition people practice. The later reversal in some countries shows the same sensitivity can run both directions.

Production constraints:
- 60 one-off scenes, 60 distinct visual keys.
- No fallback/default visual scene.
- Every historical or modern setting gets a distinct environment, camera composition, props, and motion grammar.
- Concrete environments include 1926 Tokyo workshop, 1905 Paris classroom, WWI mass testing hall, 1980s Flynn archive desk, modern phone/weather UI, subway map, classroom algebra, office dashboards, postwar household, reading-feedback child development scene, psychometrics lab, Norway conscription hall, sibling comparison, AI future classroom, and return to 1926 worker.
- Measured VOICEVOX timing, 青山龍星, narration speed tuned for 15–20 min.
- One QA frame per scene.
