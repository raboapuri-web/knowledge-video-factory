# トー横動画：章別動画レビュー方式（2026-09-23）

## 今回の制作方針

確定台本・承認済みVOICEVOX音声・字幕は維持し、映像だけを章ごとに再制作する。
299行のスプレッドシートの一括修正は必須としない。編集判断とFBの単位は**完成した章別動画**。

1. プロローグ → ユーザー確認と修正 → 章別の完成版を固定する。
2. 第1章 → 同様に確認・修正・固定する。
3. 第2章 → 同様に確認・修正・固定する。
4. 第3章 → 同様に確認・修正・固定する。
5. 第4章 → 同様に確認・修正・固定する。
6. エピローグ → 同様に確認・修正・固定する。
7. **6章が全て確認済みになった後**に、固定された章動画だけを順番に連結する。

## 根本対策

- シーン割りは**その章のナレーションの内容**に対して手動／AI推薦で設計し、映像テンプレートを7秒おきに自動挿入しない。
- 長く続く「施設の話」は施設の情景を中心にするが、同じ背景・同じ人物配置・同じ図解を一定間隔で自動反復しない。
- 図解は研究の人数、関係の構造、数字等**実際に説明が必要な箇所だけ**に入れ、違う論点に同じベン図を使い回さない。
- 章の途中で再度登場する同じ場所は、位置関係・アングル・人物動作・小道具で別の情景になるようにする。
- 必ず音声付きの短い章動画を提出してFBを受ける。承認されるまで次章の映像仕様を確定させず、旧版の全編書き出しを完成扱いしない。
- シーン変更が音声尺に影響しても、元の音声・字幕を変更せず映像シーケンスの尺だけを編集する。
- 連結時は章ごとの同一解像度・fps・音声規格と、章末の余白／章頭切り替わりを検証する。
