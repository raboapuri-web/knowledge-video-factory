# 考える夜｜ユーザー原画アセット置き場

ここに **ユーザーがアップロードした原画像そのもの** を置く（模写や再生成は禁止）。

## 必須ファイル
- **`8015.png`** （24種類の金線画アイコンを6列×4行に配置した元画像）
- 期待サイズ：1536×864 px
- 元アップロードのバイト数：140,555 bytes
- 保存先：`standalone_kangaeru_v4/brand/8015.png`

## アップロード手順
1. このフォルダーをGitHubで開く（ブランチ `kangaeru-yoru-standalone-v4-20261105`）。
2. **Add file → Upload files** を選ぶ。
3. チャットで送信済みの **8015.png を、名前も拡張子も変更せずに**選択する。
4. **Commit changes** で**このブランチへ**コミットする。mainにはコミットしない。
5. コミット後、GitHub Actions の `Kangaeru Yoru v5 genuine icons + free VOICEVOX` が起動する。

ユーザーの原画がない間は、CIはVOICEVOXの音声サンプルのみ制作し、代替アイコン入りの動画を「完成」とはしない。
原画が登録されると、原画24セルを透過抽出して使い、すべてのアイコン・動画と原画像SHA-256をartifactに収録する。
