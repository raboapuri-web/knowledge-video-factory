# 考える夜｜V150 Director's Cut V2｜制作方法と58画面の演出台帳

## 何を変えるのか

初版は58画面で少数のテンプレートを繰り返した。技術的成功を映像的成功と取り違えていた。新作は各画面の認知目標を起点に、視覚的な主役・映像モチーフ・モーションの方向を決めてからレンダリングする。

## 規則

- 親密圏＝青緑、別世界＝朱色、未知の情報を運ぶ橋＝金色として色の意味を固定する。
- 資料・データ・人間・関係・時間・選択を同一図形にしない。
- 実測VOICEVOX音声をシーン尺と字幕の唯一の基準にする。
- 字幕を下部へ分離し、日本語明朝／ゴシックを用途に応じて使い分ける。
- 静止状態を避ける微細なカメラ移動と、意味がある瞬間だけの強いモーションを併用する。
- 1920×1080 / 30fps / H.264 CRF17。全編完了後にffprobeによる映像・音声・尺の自動監査を実施する。
